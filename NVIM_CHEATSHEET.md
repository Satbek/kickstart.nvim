# Neovim Cheat Sheet

Эта шпаргалка составлена под текущий конфиг.

- `Space` = `<leader>`
- Если забыл комбинацию: нажми `Space` и подожди, `which-key` покажет подсказки
- Самые полезные команды идут сверху, более редкие ниже

## 1. Выучи это первым делом

| Команда | Что делает | Когда использовать |
|---|---|---|
| `.` | повторить последнее изменение | очень полезно после `ciw`, `x`, `p` |
| `yy` | скопировать строку | быстро дублировать или переносить строки |
| `dd` | вырезать строку | удалить строку целиком |
| `p` | вставить после курсора | вставка после `yy` или `dd` |
| `ciw` | заменить слово целиком | самый полезный edit-команд |
| `diw` | удалить слово целиком | быстро очистить слово |
| `daw` | удалить слово вместе с пробелом вокруг | часто удобнее `diw` в обычном тексте |
| `yiw` | скопировать слово целиком | взять слово под курсором |
| `/текст` | поиск вперёд | найти строку или слово |
| `*` | искать слово под курсором вперёд | быстро прыгать по одинаковым словам |
| `#` | искать слово под курсором назад | то же самое назад |
| `%` | прыгнуть к парной скобке | очень полезно в коде |

## 2. Что реально полезно запомнить сразу

| Команда | Что делает | Комментарий |
|---|---|---|
| `Space /` | поиск по текущему буферу | искать только в открытом файле |
| `Space sd` | список диагностик | все ошибки и warnings в проекте |
| `Space sh` | поиск по help | встроенная справка Neovim |
| `Space sk` | поиск по keymaps | когда не помнишь горячую клавишу |
| `Space ss` | список возможностей Telescope | если забыл, что ещё можно искать |
| `Space s.` | recent files | быстро открыть недавний файл |
| `Space sn` | поиск по файлам конфига Neovim | удобно для правки этого конфига |

## 3. Работа с окнами и буферами

| Команда | Что делает | Когда использовать |
|---|---|---|
| `<C-w>h` | перейти в левое окно | стандартная команда; у тебя есть shortcut `<C-h>` |
| `<C-w>j` | перейти в нижнее окно | стандартная команда; у тебя есть shortcut `<C-j>` |
| `<C-w>k` | перейти в верхнее окно | стандартная команда; у тебя есть shortcut `<C-k>` |
| `<C-w>l` | перейти в правое окно | стандартная команда; у тебя есть shortcut `<C-l>` |
| `:split` | горизонтальный split | открыть ещё одно окно |
| `:vsplit` | вертикальный split | открыть бок о бок |
| `:bd` | закрыть текущий буфер | закрыть файл без закрытия всего Neovim |

## 4. Поиск и переходы по коду через LSP

Эти команды работают в языках, где подключён language server.

| Команда | Что делает | Когда использовать |
|---|---|---|
| `grd` | go to definition | перейти к определению функции, типа, переменной |
| `grr` | references | найти все использования |
| `gri` | implementation | найти реализацию интерфейса или метода |
| `grt` | type definition | перейти к определению типа |
| `grn` | rename symbol | безопасно переименовать символ |
| `gra` | code action | быстрые исправления от LSP |
| `gO` | symbols in current file | обзор функций и структур в текущем файле |
| `gW` | symbols in workspace | поиск символов по проекту |
| `[d` | предыдущая диагностика | ходить по ошибкам |
| `]d` | следующая диагностика | ходить по ошибкам |
| `Space q` | список диагностик текущего окна | собрать ошибки в список |
| `Space th` | toggle inlay hints | включать и выключать подсказки типов |

## 5. Редактирование текста быстрее обычного

Это уже не базовый Vim, а то, что реально экономит время.

| Команда | Что делает | Комментарий |
|---|---|---|
| `ci"` | заменить текст внутри `"` | курсор должен быть внутри строки |
| `ci'` | заменить текст внутри `'` | то же для одинарных кавычек |
| `ci)` | заменить текст внутри `()` | удобно для вызовов функций |
| `di)` | удалить текст внутри `()` | быстро очистить аргументы |
| `va)` | выделить всё вокруг `()` | удобно перед копированием или удалением |
| `yi)` | скопировать содержимое `()` | взять аргументы или выражение |
| `ciq` | заменить текст внутри любых кавычек | `q` понимает `"`, `'`, `` ` `` |
| `daq` | удалить текст вместе с окружающими кавычками | полезно при чистке JSON, Lua, Go |
| `cia` | заменить текущий аргумент функции | даёт `mini.ai` |
| `daa` | удалить текущий аргумент функции | даёт `mini.ai` |
| `daf` | удалить вызов функции целиком | даёт `mini.ai` |
| `yinq` | скопировать текст внутри следующих кавычек | удобно, когда курсор ещё не внутри них |

## 6. Surround: добавить или заменить скобки и кавычки

Это даёт `mini.surround`.

| Команда | Что делает | Пример |
|---|---|---|
| `saiw)` | обернуть текущее слово в `()` | `word` -> `(word)` |
| `saiw]` | обернуть текущее слово в `[]` | `word` -> `[word]` |
| `sd'` | удалить окружающие `'` | `'text'` -> `text` |
| `sd"` | удалить окружающие `"` | `"text"` -> `text` |
| `sr)'` | заменить `()` на `'` | `(text)` -> `'text'` |
| `sr]}` | заменить `[]` на `{}` | `[x]` -> `{x}` |

## 7. Фолдинг

Файлы у тебя открываются раскрытыми. Фолды строятся по Tree-sitter.

| Команда | Что делает |
|---|---|
| `Space zt` | свернуть или развернуть блок под курсором |
| `Space zc` | закрыть все фолды |
| `Space zo` | открыть все фолды |
| `Space zm` | свернуть на один уровень глубже |
| `Space zr` | развернуть на один уровень |
| `za` | стандартный toggle фолда |
| `zM` | стандартно закрыть все |
| `zR` | стандартно открыть все |

## 8. Git в редакторе

Самое полезное из `gitsigns`.

| Команда | Что делает | Когда использовать |
|---|---|---|
| `]c` | следующий изменённый hunk | переход по изменениям |
| `[c` | предыдущий изменённый hunk | переход по изменениям |
| `Space hp` | preview hunk | посмотреть diff рядом |
| `Space hs` | stage hunk | подготовить только кусок файла |
| `Space hr` | reset hunk | откатить кусок правок |
| `Space hb` | blame line | кто менял эту строку |
| `Space hd` | diff against index | diff по текущему файлу |
| `Space hD` | diff against last commit | сравнение с последним коммитом |
| `Space hS` | stage buffer | добавить весь файл в stage |
| `Space hR` | reset buffer | откатить все локальные правки файла |
| `Space tb` | toggle current line blame | включить blame у строки |

## 9. Форматирование и диагностика

| Команда | Что делает | Важно |
|---|---|---|
| `Space f` | форматировать буфер | у тебя включено для Go и для этого nvim-конфига |
| `Space td` | включить или выключить diagnostics в текущем буфере | удобно временно скрыть lint/LSP ошибки в markdown |
| `:ConformInfo` | показать статус форматтеров | если форматирование не работает |
| `:checkhealth` | общая диагностика Neovim | когда что-то сломалось |
| `:Mason` | управление LSP/formatter tools | проверить, что установлено |
| `:Lazy` | управление плагинами | обновления и статус плагинов |

|---|---|
| `<Esc><Esc>` | выйти из terminal mode в normal mode |
| `:terminal` | открыть терминал |

## 11. Markdown

Для `markdown` у тебя теперь два режима: красивый просмотр прямо в Neovim и browser preview.

| Команда | Что делает | Комментарий |
|---|---|---|
| `Space mr` | toggle красивого markdown в текущем буфере | заголовки, списки, таблицы, блоки кода |
| `Space mR` | открыть rendered preview сбоку | удобно читать длинный markdown |
| `Space mp` | открыть или закрыть browser preview | тут будут локальные картинки и финальный вид |

## 12. AI-команды из твоего конфига

Это уже не базовый Neovim, а твой `CodeCompanion`.

| Команда | Что делает | Комментарий |
|---|---|---|
| `Space ca` | открыть список AI actions | точка входа в AI-функции |
| `Space a` | открыть или скрыть AI chat | чат внутри Neovim |
| `Space cc` | запустить Codex CLI | отдельная CLI-сессия |
| `Space cp` | запустить Codex CLI с prompt | удобно для разовых задач |
| `ga` | отправить выделенный текст в AI chat | работает в visual mode |
