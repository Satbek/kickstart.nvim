# AGENTS.md

## Repository notes

- This repository is a personal Neovim config rooted at `~/.config/nvim`.
- Prefer updating docs and examples so they match the actual configured keymaps and plugins in this repo.

## User cheat sheet

- `NVIM_CHEATSHEET.md` is a user-facing Neovim cheat sheet for this config.
- It is intentionally a living document: the user may remove commands they already know.
- Do not re-add removed entries unless the user explicitly asks for them again.
- Keep the cheat sheet ordered from most useful / most frequent to less useful / less frequent.
- Keep explanations short, practical, and in Russian unless the user asks otherwise.
- Only document commands that are either built into Neovim/Vim or actually available in the current config.
- When keymaps or plugins change, update `NVIM_CHEATSHEET.md` if that change affects user-visible behavior.
